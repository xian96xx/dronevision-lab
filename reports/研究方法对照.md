# 公开研究方法与 DroneVision Lab 对照

核验日期：2026-11-05。已读取四个仓库的 README、相关训练/评测脚本、配置和公开论文正文。仓库版本见 [repositories.json](../references/repositories.json)。这些是公开学术成果，本文只做方法层面的对照，本项目没有完整复现它们。

## 任务边界

| 任务 | 典型输入和输出 | 本项目对应部分 |
| --- | --- | --- |
| 目标检测 | 图像 → 每个目标的类别、框、置信度 | VisDrone + YOLO26n |
| 语义分割 | 图像 → 每个像素的类别；不区分同类实例 | UAVid + SegFormer-B0 |
| 实例分割 | 每个实例单独一张掩码 | SAM2 给提示目标生成实例掩码，但本项目未训练实例分割器 |
| 开放词汇分割 | 用文本类别描述提供推理词汇，研究未见类别迁移 | 四个参考方向中的 Pi-Seg、RSKT-Seg、MARIS；本项目未声称具备该能力 |
| 指代分割 | 根据“靠近道路的那辆车”等表达定位具体区域 | MTRefSeg 进一步要求比较两个时相的变化；本项目未训练语言指代模型 |
| 多目标跟踪 | 连续图像 → 框与跨帧身份 | 微调 YOLO + ByteTrack / BoT-SORT |

## Pi-Seg

问题：遥感开放词汇分割的跨域和未见类别迁移。模型在像素视觉特征与文本表示对齐之前加入可学习扰动，随后聚合成本图。CLIP 将类别文本与视觉特征放入可比较的表示空间；这并不保证像素位置天然准确，仍需密集分割监督。

已读配置 `configs/vitb_384_OVRSIS95K.yaml`：35 类训练、ViT-B/16、384 裁块、视觉/文本扰动开关、文本噪声标准差0.02、batch8、学习率0.0002、40K迭代。论文最新公开 v3 采用共同训练源与图像不重叠的下游评测，比较单模块、双模块、噪声分布和种子稳定性，并报告跨数据集 mIoU/mACC。论文的特征扰动与本项目故意改错训练真值属于不同干预，不能把前者当作“错误标签有益”的证据。

可借鉴：共同训练预算、分开检验模块、多个种子、人工审核和图像隔离。本项目只借鉴实验组织；未安装其 Detectron2 环境，也未运行论文的多卡完整训练。

来源：[仓库](https://github.com/LiBingyu01/Pi-Seg)、[论文 v3](https://arxiv.org/html/2604.15652v3)。注意论文与仓库 README 部分基准命名/类别计数存在版本差异，比较时须锁定版本，不能拼接不同版本的最佳数字。

## RSKT-Seg

问题：自然图像视觉语言知识迁移到遥感语义分割。RS-CMA 利用多方向的视觉文本相似度，RS-Fusion 聚合空间与类别信息，RS-Transfer 引入领域知识与上采样引导。已读配置 `configs/vitb_384_DLRSD.yaml` 明确区分 DLRSD 的 train/val 注册名、17类、CLIP-B/16、冻结 RemoteCLIP/DINO 分支、旋转开关、384裁块、batch8、30K迭代。

论文用多数据集 mIoU、mACC及组件/融合/层数/微调策略消融评估。可借鉴按类别、域和计算预算分层分析；领域适配不能仅用一张成功图论证。仓库复现脚本使用4张4090，旧环境 CUDA11.8 不适合直接照搬到 sm_120；本项目不为低优先级论文迁移而破坏已验证的 CUDA12.8 环境。

来源：[仓库](https://github.com/LiBingyu01/RSKT-Seg)、[修订论文 v3](https://arxiv.org/html/2509.12040v3)。官方 AAAI 页面本次被反爬机制拒绝，未绕过；已使用可公开获取的 arXiv 修订版本。README 提醒附录参数统计曾修订，因此不摘用旧版参数表来宣称优势。

## MTRefSeg

问题：两时相图像加自然语言指令，分割被描述的变化。公开实现使用 Swin-B / Mask2Former 视觉分支、Phi-1.5语言分支和时序融合；先做视觉变化预训练，再做语言指代微调。已读训练脚本明确 stage1 默认20轮、多卡、分支开关，README 指出默认不是 LoRA，LoRA属于专门消融。数据需要 A/B 图像、mask和指代表达，不能用普通 MOT ID 直接替代。

评测代码同时累计逐样本IoU和全体像素交并比，并显式处理空真值/空预测。这与 UAVid 按类别平均的 mIoU 不是同一定义。可借鉴多阶段初始化对照、自动构建加人工审核，以及空目标样本处理。完整多模态微调和自定义 CUDA算子超出本项目必要范围，未作完整复现。

来源：[仓库](https://github.com/LiBingyu01/MTRefSeg)、[论文](https://arxiv.org/html/2606.00987v1)、`scripts/run_stage1_visual_pretrain_TV.sh`、`segearth_r1/eval_and_test/eval_change.py`。

## MARIS

问题：水下开放词汇实例分割，属于水下场景，不是无人机遥感数据。GPEM引入几何结构先验，SAIM改善领域文本语义匹配。已读 in-domain配置选择 ConvNeXt CLIP 和实例输出；基础配置指定mask分类、掩码和Dice损失权重、250个查询及几何分支开关。训练文档分别组织 WaterOVS 与 COCO→水下的跨域设置，论文使用4张24GB的4090，采用实例mask AP等指标。

可借鉴：分别测域内与跨域、模块组合和逐类失败案例；视觉清晰度与类别语义都可能造成错误。我们的 bbox mAP、UAVid mIoU与其mask AP不可直接排名。代码涉及修改版Detectron2与MSDeformAttn，未迁入主环境，未声称复现其成绩。

来源：[仓库](https://github.com/LiBingyu01/MARIS)、[论文 v3](https://arxiv.org/html/2510.15398v3)、`GETTING_STARTED.md`、`configs/convnext_base_waterovs_id.yaml`。

## 对本项目实验设计的具体影响

| 借鉴原则 | 本项目落实方式 | 尚不能声称什么 |
| --- | --- | --- |
| 固定训练与评测口径 | 标签噪声组相同图片、预算和初始权重，干净验证集固定 | 未完成训练时不能声称噪声影响已验证 |
| 消融只改研究变量 | 检测偏移/漏标分开；分割边界/局部错标分开 | 不把多项同时修改的提升归因于某一项 |
| 检查域和输出语义 | DET与MOT不混训；SAM掩码先转框比较 | 不用框IoU证明掩码边缘准确 |
| 人工审核可量化 | 遮挡、转向、尺寸变化、漏检、ID切换可作为复核线索 | 没有人工改标对照时不宣称人工审核必然提高mAP |
| 控制偶然性 | 检测噪声重复3个种子，报告配对差值与波动 | 小子集不代表所有无人机场景 |
