# 第二轮实际执行源码快照

这里保留七组新增训练实际执行时的 `segmentation.py` 与队列脚本，SHA256 索引见 `reports/refinement-code-provenance.json`。

当前 `scripts/segmentation.py` 在这些训练完成后增加了续训时保留更早最佳验证检查点的修复；该修复不回写七组原实验记录。检查点副本续训由当前脚本实际执行，其实现SHA在独立训练记录中。

需要严格重放这轮训练时，在新的项目副本中按README准备公开数据与模型，将本目录两个快照复制到新副本的 `scripts/` 下，再运行队列命令。快照的 `ROOT` 按原 `scripts/` 层级计算，不应直接在本快照目录运行。选择新的实验工作目录，保留已有数据、对照模型及报告。

源码新环境冒烟复跑的记录没有随公开仓库发布。训练和续训的验证范围不同，不能互相替代。
